- 原同步目录与 iCloud 原件不变；仓库保存副本与来源映射。
- 旧文件名的重复编号被移入来源清单，仓库使用稳定名称。

- 旧登录参数不入库；临时 Figma 下载地址只用于下载，不进仓库历史。
- 不伪造历史 Git 提交，也不补写不存在的测试、成果或数据。
