# 术语表

| 术语 | 本项目中的含义 |
|---|---|
| Pre-arrival care | 客人抵达前的关照，连同到店后的兑现 |
| Recognition | 感到酒店认识、记得并理解自己的情境；仍需具体研究 |
| Intent | 说明解决什么、服务谁的目标的工作陈述 |
| Facts / Assumptions / What to Check | 资料分类；受访者陈述仍需注明来源与限制 |
| NPS | Net Promoter Score；本项目没有提供已验证的改善结果 |
| Price tolerance / willingness to pay | 客户提出的价格接受度 / 支付意愿目标 |
| Brand equity | 客户提出的品牌资产目标 |
| Cost to serve | 交付和支持服务所需成本 |
| LQE | Legendary Quality Experience；Kate 描述的品牌标准 |
| LQA | 访谈提及的外部质量评估；不能与 LQE 混同 |
| Fans / Silk / Pearl | 访谈使用的会员层级框架；历史描述不代表当前政策 |
| Urban / Urban Resort / Destination Resort | 酒店类型；并非房间类型 |
| Agent | 方案中替老板安排入住的人类助理 / 代理人；不是 AI agent，也不是本仓库协作 agent |
| Dream Maker | 当前设计成果中的服务与操作流程名称 |
| Default / Personalized / Custom | 需求设置表达的三种方式；并非价值高低排序 |
| As-Is / To-Be | 现状与拟议服务状态 |
| Simple simulation | 简单模拟；不能替代真实用户或酒店运营测试 |
