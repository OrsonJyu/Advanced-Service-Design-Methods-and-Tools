# 项目概览 / Project overview

## 背景
香港理工大学 SD5412 Advanced Service Design Methods and Tools 课程，Mandarin Oriental 服务设计课题。初始 brief 聚焦完成预订至抵达和入住之间：如何建立关照与期待，同时避免酒店承诺超过运营能力。

## 工作 Intent
2026-09-08 的工作版本：

> We are solving for pre-arrival care that helps guests feel recognised and can be delivered reliably at manageable cost and complexity, in service of Mandarin Oriental’s goal of strengthening brand equity and guests’ willingness to pay.

这句话的目标主体是酒店；尚不能把酒店希望客人感到被理解，直接当作客人自己表达的目标。它代表早期讨论，不应未经核对称为最终 Figma 版本的逐字 Intent。

## 核心边界
- 关照需要在入住中被感知，App、邮件、Agent 只是连接这一服务的触点。
- 隐私、自主权、服务标准、成本、周转与临时换房影响可兑现性。
- NPS 是客户提出的风险底线；brand equity、price tolerance 是目标。
- “满足期待等于中性”是经验解释，不是 NPS 的计算公式。
- 初始项目聚焦预订后；后来的 Agent 预订方案扩展了触点，需在解释范围时说明。
